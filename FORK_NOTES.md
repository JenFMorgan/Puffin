# Fork notes

This is an ongoing development fork of **Puffin** (Parallel Unaveraged Fel
INtegrator), a 3D unaveraged FEL simulation code originally developed at the
**University of Strathclyde** by Brian McNeil, Lawrence Campbell, and
co-workers.

The original Puffin code, and all credit for its core development, belongs to
the original authors. This fork tracks ongoing extensions and additions made
on top of Puffin as they're developed, rather than being scoped to a single
feature.

## Branch layout

- **`master`** mirrors the current upstream `UKFELs/Puffin` repository,
  including the recent restructuring of the codebase into the `puffin/lib/...`
  layout.
- **`fieldmap-old-layout`** contains the additions described below. This
  branch was developed against the codebase prior to the recent
  restructuring, and has not yet been reconciled with the new layout.

## Additions in this fork

Each addition is documented briefly here, with a link to further detail
(paper, manual, or example) where available. This list will grow over time.

### Arbitrary magnetic field import via HDF5
*(on `fieldmap-old-layout`)*

Support for a new lattice element (`UNF`) that reads an externally supplied
3D magnetic field map from an HDF5 file, rather than using a built-in
analytical field description (e.g. ideal planar/helical wigglers). Field
values are interpolated onto electron macroparticles using trilinear
interpolation. Validated against analytical benchmarks in both the
steady-state and exponential-gain regimes, with a resolution/convergence
study characterizing field-map sampling requirements.

See `docs/external-field-map/notes.pdf` for full details, and
`examples/planar-field-map/` for a worked example. A paper describing this
work is in preparation and will be linked here once available (FEL2026
proceedings).

## Examples

`examples/planar-field-map/` contains the exact files used to produce the
validation case in the accompanying paper: a notebook that generates the
field map (`MakeBField_plannar.ipynb`), the corresponding Puffin input decks,
and the benchmark comparison plot. The HDF5 field-map file itself is not
committed (it's regenerated by the notebook) — see `.gitignore`.

**Note:** this repository also contains a `doc/` directory with the original
Puffin documentation (including its own `manual.pdf`). That is unrelated to
this fork's additions — the notes for this feature are in
`docs/external-field-map/notes.pdf`.

**Note:** this repository also contains an `inputs/` directory with older
example decks. Those are out of date and unrelated to this fork's additions.
The current, paper-referenced example is in `examples/planar-field-map/`.
